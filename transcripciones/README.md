# Transcripciones y Minutas Procesadas

Directorio para almacenar los textos transcritos en formato Markdown (`.md`) derivados de las grabaciones de reuniones, sesiones de trabajo y tutorías.

## Estructura Recomendada de Archivos:

- `YYYY-MM-DD_reunion_supervisor_[tema].md`
- `YYYY-MM-DD_tutoria_academica.md`

## Formato del Archivo Transcrito:

```markdown
# Transcripción: [Título de la Reunión]

- **Fecha:** YYYY-MM-DD
- **Participantes:** Eryck FCS, [Supervisor Institucional / Tutor]
- **Duración del Audio:** XX min
- **Objetivo:** [Tema central tratado]

---

## 1. Puntos Clave Tratados
- Punto 1...
- Punto 2...

## 2. Compromisos y Tareas Asignadas
- [ ] Tarea 1...
- [ ] Tarea 2...

---

## 3. Transcripción Literal / Resumen Estructurado
[Contenido transcrito depurado]
```
