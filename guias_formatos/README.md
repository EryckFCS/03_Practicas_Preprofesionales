# Guías y Formatos Oficiales — Prácticas Preprofesionales

Este directorio almacena la normativa, formatos institucionales y guías emitidas por la Universidad Nacional de Loja (UNL) para la acreditación de prácticas preprofesionales finales.

## Contenido:

1. `formato_bitacora_semanal.md`: Plantilla estándar para el registro de actividades diarias y cálculo de horas semanales.
2. `formato_informe_final.md`: Estructura para el informe consolidado final con rúbrica institucional.
3. Formatos adicionales (colocar aquí documentos oficiales en PDF/DOCX emitidos por la Dirección de Carrera o la UNL).
