# Proyectos Técnicos y Arquitectónicos

Directorio especializado para el almacenamiento, análisis técnico-económico y evaluación de proyectos desarrollados durante las prácticas en la Carrera / Facultad de Arquitectura (UNL).

## Estructura de Trabajo:

1. **`levantamientos_planos/`**:
   - Planimetrías, esquemas arquitectónicos, archivos DXF/DWG/PDF y documentación gráfica de las áreas o infraestructuras intervenidas.
2. **`presupuestos_costos/`**:
   - Análisis de Precios Unitarios (APU), matrices de costos directos e indirectos, cronogramas valorados de obra y metrados de materiales.
3. **`fichas_tecnicas/`**:
   - Especificaciones técnicas de materiales, normativas de construcción aplicadas y fichas de diagnóstico situacional.
4. **`memorias_descriptivas/`**:
   - Informes técnicos y memorias descriptivas que articulan la dimensión arquitectónica con la sostenibilidad financiera y el impacto socioeconómico.
