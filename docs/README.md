# Documentación Académica y Bóvedas de Evidencia (Vaults)

Este índice organiza la documentación viva del nodo de Prácticas Preprofesionales (Octavo Ciclo - UNL). El repositorio opera bajo la arquitectura federada de nodos descentralizados.

## Estructura Documental:

- **`syllabus/`**: Sílabo oficial, itinerario formativo y cronograma institucional de prácticas preprofesionales.
- **`normativa/`**: Reglamentos institucionales UNL, directrices de titulación y prácticas en territorio.
- **`vaults/`**: Bóvedas modulares de evidencia vivas para el desarrollo de las prácticas preprofesionales:
  - `v01-diagnostico-planificacion/`: Plan de actividades, inducción, diagnóstico institucional y objetivos iniciales.
  - `v02-ejecucion-actividades/`: Ejecución operativa, análisis presupuestario, proyectos arquitectónicos y bitácoras activas.
  - `v03-cierre-evaluacion/`: Consolidación del informe final, rúbricas de evaluación del tutor y acreditación de horas.

---

## Criterio Documental:
- Las evidencias vivas de trabajo se concentran exclusivamente en `docs/vaults/`.
- Todos los documentos `.qmd` están preparados para renderizado estandarizado en HTML o PDF mediante Quarto.
